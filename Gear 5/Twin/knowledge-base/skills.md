# My Technical Skills

## My skills at a glance

My technical skills are centered on AI engineering: Python, large language models, RAG, agentic AI, fine-tuning, and computer vision. I back these with data and database skills, web scraping, application development, and the tools I use to build and ship projects.

## Programming languages

My main language is Python. I also know SQL, and I have C/C++ fundamentals and x86 Assembly fundamentals.

## LLMs and AI platforms

I work with LLMs through the OpenAI APIs and Google Gemini, and I have used GPT-4.1, GPT-4.1-nano, GPT-5.1, and GPT-5-mini, as well as Llama 3.2. I use LiteLLM to call different models through one interface. In DealScout I used GPT-5-mini to pick deals and write alerts, and in my AI Brochure Generator I used GPT-4o-mini and Gemini 2.0 Flash. I also do prompt engineering and tool calling (function calling).

## RAG and vector search

I build RAG systems with embeddings, semantic search, and vector databases. I use ChromaDB as a persistent vector store, OpenAI's `text-embedding-3-large` for embeddings, and I do document preprocessing, retrieval pipelines, vector similarity search, and reranking, including BGE rerankers. In Fifa_Box I combined dense retrieval with BM25 keyword search, query rewriting, and cross-encoder reranking, and built an evaluation suite for it. In DealScout I used retrieval of similar products for price estimation.

## Agents and LLM frameworks

I build agentic AI systems with LangChain and use agent orchestration, tool-based agents, planning agents, autonomous agents, multi-agent workflows, and API-based tool integration. In DealScout I built a 7-agent system in both a fixed workflow and a fully autonomous mode where the LLM chooses which tools and agents to call.

## Fine-tuning and model training

I fine-tune language models with parameter-efficient methods: PEFT, LoRA, and QLoRA with quantization. I use the Hugging Face ecosystem, including Transformers, and I track training experiments with Weights & Biases. In DealScout I fine-tuned Llama 3.2 3B with QLoRA for price prediction and deployed it on Modal.

## Machine learning and deep learning

I work with PyTorch, TensorFlow, and scikit-learn. My ML skills cover supervised and unsupervised learning, classification and regression, feature engineering, neural networks, transfer learning, model evaluation, and semantic similarity. I trained a custom PyTorch neural network for DealScout and a custom gesture classifier for Shadow Clone Jutsu.

## Computer vision and multimodal AI

I work in computer vision and vision-language AI, including BLIP and BLIP-2, image-to-text, vision-language pipelines, and image generation with Stable Diffusion and SDXL. In Shadow Clone Jutsu I used OpenCV, MediaPipe, and TensorFlow for real-time hand gesture recognition and person segmentation.

## Data and databases

I work with PostgreSQL, SQLAlchemy, and relational database design, including normalization, SQL queries, and CRUD operations. For data work I use Pandas, NumPy, JSON and JSON parsing, and data preprocessing.

## Web scraping and automation

I do web scraping and data extraction with Beautiful Soup and Selenium, including HTML parsing and browser automation, and I work with RSS feeds. In my AI Brochure Generator I used Requests and Beautiful Soup, and in DealScout I scanned RSS deal feeds.

## Application development and APIs

I build applications with Flask, Gradio, and PySide6. I also work with REST APIs and Python API integration, and I manage configuration with environment variables and `.env` files. I used Gradio for DealScout and the AI Brochure Generator, and built the Fifa_Box desktop app with pywebview and a hand-built HTML, CSS, and JavaScript frontend.

## Deployment, cloud, and experiment tracking

I deploy models to the cloud with Modal (modal.com), where my fine-tuned Llama model for DealScout runs on a T4 GPU, and I publish models through Hugging Face. I track experiments with Weights & Biases. I also use Google Colab for training.

## Data visualization

I build visualizations with Plotly, including interactive charts, and I use t-SNE to visualize embeddings. In DealScout I built a 3D visualization of the product embeddings.

## Software development fundamentals

I have a foundation in object-oriented programming, data structures and algorithms, API integration, authentication systems, backend development, email integration, debugging, and error handling.

## Development tools

I work with Git and GitHub, VS Code, uv, Python virtual environments, PowerShell, Jupyter Notebook, and Google Colab.
