## About

Gear 3 is where things get serious. Every project here taps into the real power of modern LLMs — built during a focused learning phase with Gemini and OpenAI APIs. Not just scripts, but actual AI-powered apps with interfaces. This folder will keep growing as more LLM projects come to life.

| ✈️ FlightAI | Gradio | AI agent for flight booking and ticket info |

## Getting started
```bash
git clone https://github.com/HAIDERALiiii01/ProjecTss
cd "ProjecTss/Gear 3"
pip install -r requirements.txt
python <project_name>.py
```

## Requirements

- Python
- Gradio — `pip install gradio`
- API keys — Gemini or OpenAI depending on the project. Add them as environment variables or in a `.env` file.
