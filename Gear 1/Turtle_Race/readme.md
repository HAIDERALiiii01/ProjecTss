## 🎯 What it does

A fun turtle racing game built with Python Turtle. Six colored turtles line up and race to the finish. You predict which color will win before the race starts — then watch it unfold. Pure luck, pure chaos.

---

## 📁 Files

| File | Description |
| --- | --- |
| `battle_of_the_strongest.py` | 🚀 The entire race — run this to start |

---

## ⚙️ How it works

1. **Prediction** — A dialog box asks you to pick a color before the race begins
2. **Race** — Six turtles move forward by a random amount each tick
3. **Winner** — The first turtle to cross the finish line wins
4. **Result** — A message tells you whether your prediction was correct or not
5. **Exit** — Click the screen to close after the race ends

---

## 🎮 How to play

- Type one of the following colors when prompted: `red`, `blue`, `green`, `yellow`, `purple`, `black`
- Watch the race unfold
- Win or lose — click the screen to exit

---

## 📝 Notes

- No external libraries required — pure Python
- Each turtle moves a random distance between 0 and 10 per tick — completely unpredictable
- The result is displayed on screen above the track once the race ends
