## 🎯 What it does

A terminal-based Rock Paper Scissors game with text-to-speech commentary and a surprise ending. The computer talks to you throughout the game, trash talks a little, keeps score in dollars, and when you quit — it creates a folder on your Desktop with a very special audio file about your winnings. 😏

---

## 📁 Files

| File | Description |
| --- | --- |
| `ROCK_PAPER_SCISSOR_NEXT_LEVEL.py` | 🚀 The entire game — run this to play |
| `KYU.mp3` | The surprise audio that plays when you try to collect your winnings 😂 |

---

## ⚙️ How it works

1. **Introduction** — The game introduces itself out loud with full attitude
2. **Rounds** — You pick Rock, Paper or Scissors each round against the computer
3. **Score** — Every win earns you $1000, tracked throughout the session
4. **Exit** — Type `exit` to quit and collect your "winnings"
5. **Surprise** — A folder called `HERE_COMES_THE_MONEY` appears on your Desktop with an audio file inside 💀

## 🚀 Getting started

### 1. Clone the repository
```bash
git clone https://github.com/HAIDERALiiii01/ProjecTss
cd "ProjecTss/Gear 1/Rock_Paper_Scissor"
```

### 2. Install dependencies
```bash
pip install pyttsx3
```

### 3. Run the game
```bash
python ROCK_PAPER_SCISSOR_NEXT_LEVEL.py
```

## 🎮 Controls

| Input | Action |
| --- | --- |
| `1` | Rock |
| `2` | Paper |
| `3` | Scissors |

## 📝 Notes

- `KYU.mp3` must be in the same directory as the script for the ending to work
- Uses `pyttsx3` for offline text-to-speech — no internet required
- The game runs indefinitely until you type `exit`
- The Desktop folder and audio file are the real prize — trust the process 😂
